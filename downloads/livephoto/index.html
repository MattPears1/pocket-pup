iPhone Steps

Download the light mode MOV, save it to Photos, then use an iPhone app such as VideoToLive to convert the video into a Live Photo. In Photos, select the Live Photo, tap Share, then Use as Wallpaper. Set it for the Lock Screen, keep Spatial Scene off, and enable the Live Photo motion button if shown.
